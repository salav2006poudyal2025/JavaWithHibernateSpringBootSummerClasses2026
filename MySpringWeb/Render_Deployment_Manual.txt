================================================================================
          MYSPRINGWEB - COMPLETE MANUAL SETUP & RENDER DEPLOYMENT GUIDE
================================================================================

This document outlines the remaining manual actions you need to take to fully 
configure, test, and deploy your MySpringWeb application to Render.

Note: Your Database, Email (SMTP), and Cloudinary configurations have already 
been successfully integrated into the application's source code!

Follow this guide from top to bottom.

--------------------------------------------------------------------------------
STEP 1: JWT SECURITY SETUP
--------------------------------------------------------------------------------
A dummy JWT secret is currently hardcoded in application.properties. For 
production, you MUST change this to a secure random string.

File to edit: src/main/resources/application.properties

1. Generate a random 256-bit (64 character) Hex string. You can use an online 
   generator or run: openssl rand -hex 32
2. Replace the jwt.secret value:
   jwt.secret=YOUR_NEW_SECURE_64_CHAR_HEX_STRING

--------------------------------------------------------------------------------
STEP 2: GIT & GITHUB SETUP
--------------------------------------------------------------------------------
Render deploys applications directly from GitHub. You must push your code there.

1. Open a terminal in your project root (d:\DocFile\MySpringWeb\MySpringWeb).
2. Initialize Git (if not already done):
   git init
3. Add all files to staging:
   git add .
4. Commit your changes:
   git commit -m "Initial commit with enterprise features and configurations"
5. Go to GitHub.com and create a new Private repository (Private is recommended 
   since your credentials are currently hardcoded in the source files).
6. Link your local repo to GitHub:
   git remote add origin https://github.com/your-username/your-repo-name.git
7. Push your code:
   git push -u origin main (or master)

--------------------------------------------------------------------------------
STEP 3: RENDER DEPLOYMENT SETUP
--------------------------------------------------------------------------------
Your project already has a Dockerfile configured for Render deployment.

1. Go to https://render.com/ and sign in with GitHub.
2. Click "New +" and select "Web Service".
3. Connect the GitHub repository you just created.
4. Fill in the deployment details:
   - Name: my-spring-web (or whatever you prefer)
   - Region: Select the one closest to you or your database.
   - Branch: main (or master)
   - Environment: Select "Docker" (CRITICAL: Do NOT select Java/Maven, the AI 
     provided a Dockerfile to ensure smooth deployment).
   - Instance Type: Free (if available) or Starter.

--------------------------------------------------------------------------------

STEP 5: DEPLOY AND VALIDATE
--------------------------------------------------------------------------------
1. Click "Create Web Service" on Render.
2. Render will pull your GitHub repository, build the Docker image using the 
   Dockerfile provided, and start the application on port 8080.
3. Watch the Render deployment logs. It should take around 3-5 minutes.
4. Once deployed, Render will give you a public URL (e.g., https://myspringweb.onrender.com).
